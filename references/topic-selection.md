# 选题转化：素材 → 角度 → 选题卡

辅导员「不知道写什么」的根子，是没有把「工作素材」翻译成「学生关心的东西」和「有张力的矛盾冲突」。本文给一套固定打法：**五角度框架 + 三步法**，任何素材都能稳定产出选题。

## 一、五角度框架

五个切入角度，每个角度记住四要素：**定义 / 素材特征 / 标题句式 / 常见误区**。

| 角度 | 定义 | 典型素材特征 | 标题句式示例 | 常见误区 |
|---|---|---|---|---|
| **成长** | 个体蜕变、从跌倒到站起、第一次做到 | 挂科后逆袭、从怯场到上台、改掉一个坏习惯 | 「那个挂科三门的学生，后来…」「从不敢说话到…」 | 只写结果不写过程，成长变鸡汤 |
| **选择** | 取舍与代价、两难抉择、代价之后的成长 | 转专业、考研 vs 就业、放弃保研去基层、参军 | 「当保研名单出来，他删掉了…」「选错一次，然后呢？」 | 站队式结论，非黑即白 |
| **责任** | 担当、承诺、该不该扛、扛起之后 | 班干部背锅、替室友扛事、违约与担当、主动揽活 | 「这件小事，他扛了四年」「没人要求，但我觉得应该」 | 道德绑架式说教 |
| **关系** | 师生 / 同窗 / 亲子 / 恋人的理解与误解 | 一次谈心化解误会、室友矛盾、代际冲突、师生误会 | 「那晚办公室的灯亮到…」「你误会了我三年」 | 只煽情不讲关系如何修复 |
| **家国情怀** | 小我融入大我、个人选择与时代同频 | 入伍、西部计划、支教、重大时间节点的个人选择 | 「他去当兵那天，班里…」「把青春写在…」 | 硬拔高、口号式升华 |

**用法**：不是五选一，而是给每个角度打分，挑分数最高的一到两个做。一个素材往往「成长」+「选择」双高，就写「在选择中成长」。

## 二、三步法 prompt（直接复制，替换 {素材}）

```text
【素材】
{辅导员粘贴的工作素材：事件经过 / 谈话要点 / 班会设计}

【任务】分三步产出选题卡：

第一步——学生真正关心什么：抛开辅导员视角，站在学生位置写出他们在这件事里最在意的 3 个点（利益 / 情绪 / 面子 / 前途），并注明依据。

第二步——矛盾冲突：一句话概括素材的核心张力（个体 vs 集体 / 理想 vs 现实 / 短期爽 vs 长期成长 / 自由 vs 责任 …），说明为什么它有张力。

第三步——五角度匹配：对成长 / 选择 / 责任 / 关系 / 家国情怀逐角度打 0-5 分，写一句打分理由。

【输出】选题卡（选 1-2 个最佳角度，每个给）：
- 角度 + 分数
- 核心冲突（一句话）
- 标题 3-5 个（含悬念式、反问式、故事式各至少一个）
- 开头钩子一句话
- 目标读者画像（谁在看、为什么转发）
- 价值升华落点（一个不拔高的自然落点）
```

## 四、质量自检（出选题卡前问自己）

- 标题里有没有「具体的人 / 具体的数字 / 具体的反差」？没有就是空标题。
- 核心冲突是不是真的两难？「该不该好好学习」不是冲突，「想留下陪家人 vs 想去西部支教」才是。
- 价值升华落点是不是素材本身能长出来的？拔上去就砍掉。
- 目标读者画像清不清楚？「给全校学生看」不算画像，「给正在纠结考研还是就业的大三学生看」才算。
