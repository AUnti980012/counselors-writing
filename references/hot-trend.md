# 抓热点：热榜站主路径 + 抖音实验项

热点是**可选环节**——不是每篇都要蹭，硬蹭比不蹭更伤。目标是找「热点 × 学生工作」的真实接口。

## 一、主路径（默认）：第三方热榜站

稳定、零风控风险，优先用（M3 起统一入口 `kb.py hotlist`，输出 JSON `[{rank,title,heat,url}]` 与 V1 逐字段一致；抓取原始响应自动落 `cache/raw` 幂等复用，合规重试 ×3 退避 2/4/8s）：

| 源 | 说明 | 抓取方式 |
|---|---|---|
| **微博热搜** | 学生关注度最高，ajax API 最稳、无需登录 | `kb.py hotlist weibo` |
| **tophub.today** | 聚合微博/知乎/百度/抖音多榜（已过滤电商带货） | `kb.py hotlist tophub` |

```bash
python scripts/kb.py hotlist weibo --top 20      # 主推：微博热搜
python scripts/kb.py hotlist tophub --top 20     # 聚合多榜
```

> V1 兼容入口：`python scripts/legacy/fetch_hotlist.py weibo --top 20`（输出一致）。
> 新榜已移除（反爬不可直抓）。需要公众号内容风向时用搜索引擎搜「今日公众号热点」或直接访问官方榜单页。

抓取失败时降级：换备用源 → 用搜索引擎兜底搜「今日微博热搜榜」→ 仍不行就直接放弃蹭热点（热点不是硬门槛）。

## 二、热点 → 选题桥接 prompt（避免硬蹭）

```text
下面是今日热点榜单（JSON）和我要写的素材。请找 1-2 个「热点与学生工作的真实接口」：
- 接口要真实（学生的确有这个情绪/处境），不要硬套；
- 找到后说明：这个热点提供了什么「情绪入口」或「公共语境」；
- 找不到就说找不到，宁可不蹭也不要牵强。

热点：{kb.py hotlist 输出}
素材：{素材}
```

榜单只取前 20 条、只注入 rank+title 摘要，不要把整份 JSON 全文回灌。

## 三、抖音 CDP 实验项（标注风险）

抖音/今日头条是字节系强反爬平台，静态抓取基本拿不到，唯一现实路径是 `web-access-main` 的 CDP 浏览器。

**明确风险**：账号风控 / 封禁、依赖登录态、成功率不保证。**操作前必须告知用户「抖音为实验项、有封号风险」，并遵守登录同意门禁（见下）。**

操作（实验性）：

```bash
# 1. 前置检查 + 拉起 CDP 代理（需 Node.js 22+；路径按你的 web-access-main 安装位置）
node <web-access-main>/scripts/check-deps.mjs

# 2. 走本 skill 封装（内部：打开抖音 → 滚动触发懒加载 → 结构化提取）
python scripts/fetch_douyin.py <关键词> --top 20
```

**输出（C-02 结构化改造）**：JSON `[{title, topic, likes}]`，字段限长截断（title ≤100 / topic ≤50 / likes ≤32），**不再输出整页 innerText**。

**登录同意门禁**：脚本检测到热榜需要登录态且未带 `--consent` 时，输出结构化状态 `{"status": "login_required", ...}` 并退出。此时**询问用户**：
- 同意 → 用其本机已登录浏览器，加 `--consent` 重试；
- 拒绝 → 降级为「用户提供热点内容」（粘贴/截图），或直接跳过抖音。

**降级纪律**：任何一步失败即退出并跳过抖音，只用热榜站；不反复重试触发风控。

## 四、用热点的三条底线

1. **真实接口优先**：热点只是「情绪入口」和「公共语境」，不能成为正文主角。
2. **时效短**：热搜级热点保鲜期通常 24-48 小时，过期就撤。
3. **不碰敏感**：涉政治敏感、群体对立、争议人物、灾难消费的热点一律不蹭，直接跳过。
