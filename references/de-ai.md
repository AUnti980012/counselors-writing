# 去 AI 味（两层：确定性门禁 + 判断清单）

去 AI 味分两层，**能不用 LLM 就不用**：

1. **确定性门禁（零 LLM）**：`kb.py deai` 把 Humanizer-zh 31 条模式里「纯表面/机械」的部分做成规则，机器自动发现 + 自动修，不花 token。
2. **判断清单（写作时人/LLM 守）**：需语境判断的模式，只列最关键的几条，边写边守，不单独跑一次 LLM。

## 一、确定性门禁 `kb.py deai`（零 LLM）

```bash
# 检查：输出机器可读 findings（exit 0 通过 / 2 有 findings）
python3 scripts/kb.py deai <正文文件>
cat 正文.txt | python3 scripts/kb.py deai

# 自动修：只应用「纯机械」项，输出修正文本（不落盘，由你确认后应用）
python3 scripts/kb.py deai --fix <正文文件>
```

**自动修（AUTO_FIX，无歧义才改）**：

- 限定词堆叠：`也许可能` → `可能`（§9）
- 进行＋动词：`进行了测试` → `测试了`（§27）
- 纯过渡连接词：删句首 `总而言之，/综上所述，/值得一提的是，/换言之，/不难发现，/由此可见，`（§31）
- 段末总结句引导语：删 `这告诉我们，/这启示我们，/这充分说明，`（保留结论本身）
- 装饰性 emoji：删除（§20）

**只标不修（FLAG_ONLY，需语境判断，出 warn 交你/LLM 定夺）**：

- 序列连接词 `首先/其次/最后`（可能承载真实顺序，§6）
- 客服腔 / CTA `好问题！/欢迎点赞在看转发`（公众号结尾可能有意，§22）
- 起跑式铺垫 `接下来让我们深入看看`（§4）、`随着…的发展` 开头（§30）
- 假对比 `不仅…更是…` / `不是…而是…`（§1）
- AI 高频词 `赋能/闭环/抓手/打造/聚焦/践行…`（§12）
- 意义拔高 `标志着/里程碑/新纪元/不懈追求`（§13）、句尾拔高 `彰显了/堪称/梦想天堂`（§15/16）
- 翻译腔 `做了一个决定` + 有中译的英文词 `performance/issue`（de-ai.md #7）

**分工**：破折号（em-dash）由标点门禁 `kb.py punctuation` 统一处理，deai 不重复。

完整规则表（含每条对应的 Humanizer §编号、正则、修复函数）在 `scripts/core/deai.py`，是单一真相源。audit 里的 `deai` 检查项即由本门禁确定性注入（零 LLM）。

## 二、判断清单（写作时守，不单独跑 LLM）

写每一段时就守下面几条，不要等全文写完再返工：

1. **删段末总结句**：`这说明…` `由此可见…` `说到底…` 这类无独立信息的收尾——引导语 deai 已自动删，整句判断删不删由你定。
2. **删硬升华**：每段结尾强行点题、上价值；升华要从事自然走到理，不硬贴口号。
3. **拆排比堆砌**：三连排比以上、对仗工整得像对联的，改成自然句。
4. **改翻译腔**：`X 的 Y 比 Z 更 W` 式抽象主语、`他做了一个决定` 式物理动作动词，改成口语。
5. **少用「我们都要」「让我们」**：多用短句、口语、具体细节。

## 三、判断标准一句话

读一遍，如果「这像真人辅导员在和学生说话」，就合格；如果「这像 AI 写的公文 / 知乎体 / 教科书」，就还没过关。确定性门禁只是兜底机械项，语义判断仍靠这条标准。
